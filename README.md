# HCI 6조 지하철 QR 민원신고 프로토타입 (통합본)

화면과 행동 기록: 박유라 프로토타입 기반 · QR 접속과 GitHub 배포: 정지우 프로토타입 기반

| 파일 | 역할 |
| --- | --- |
| `index.html` | 참가자 화면. QR 주소(`?car=칸번호&key=키`)로만 열리고, 키가 없거나 틀리면 차단 화면 |
| `dashboard.html` | 연구자 대시보드. 완료율, 소요시간, 클릭, 화면별 체류시간, 참가자별 행동 기록 |
| `qr.html` | 시연용 QR 스티커 인쇄 페이지 |
| `assets/config.js` | 칸 데이터(호선, QR 키, 온도, 몇 번째 칸)와 수집 서버 주소 |
| `tools/collector.gs` | 구글 시트 수집 서버 코드 (설치 방법은 파일 맨 위 설명) |

## 평가 진행
1. `qr.html`을 열어 QR을 인쇄하거나 화면에 띄워요.
2. 참가자가 폰 카메라로 QR을 찍으면 참가자 코드 입력 → 동의 → 측정 시작.
3. 접수 완료 화면에 도달하면 성공으로 기록돼요.
   - 수집 서버 연결 시: 기록이 구글 시트로 자동 전송 → 대시보드에서 비밀번호 입력 후 '수집 서버에서 불러오기'
   - 연결 전: 완료 화면의 '사용성 평가 기록 저장'으로 JSON을 받아 대시보드의 'JSON 기록 가져오기'로 합치기
4. 기록 없이 시연만 할 때는 QR 주소 끝에 `&study=off`를 붙여요.

## 주의
- 칸 번호와 키(`assets/config.js`)를 바꾸면 이미 인쇄한 QR이 작동하지 않아요.
- 온도, 처리 상태, 문자 안내는 모두 시연용이에요. 실제 민원은 접수되지 않아요.
